Get Quire. It's free.

Installed copies update themselves.

Mac

Open Terminal (⌘Space, type Terminal), paste, press Return. No security warning.

curl -fsSL https://getquire.pages.dev/install.sh | sh

Prefer the .dmg? Drag Quire to Applications and open it. When macOS can't verify the app, click Done, then System Settings › Privacy & Security › Open Anyway.

Windows

Open PowerShell (Start, type PowerShell), paste, press Enter. No SmartScreen warning.

irm https://getquire.pages.dev/install.ps1 | iex

Prefer the .exe? If SmartScreen appears, click More info › Run anyway. All versions

Questions

Is it really free?

Yes, and open source. Sharing includes 25 MB of cloud space; only shared files use it.

Do I need an account?

Only to share or comment. Everything else works signed out.

Does it change my original files?

Imports are copies; originals stay put. Folders you add from your Mac are edited in place, with every version kept.

Why does my Mac warn me the first time?

Quire isn't signed with a paid Apple certificate yet, so macOS can't vouch for it. Installing with the Terminal command skips the warning, or click Open Anyway in System Settings › Privacy & Security. The code is public and every update is signed.
