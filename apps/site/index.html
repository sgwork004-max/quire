Get Quire

Free, for Mac and Windows. Installed copies update themselves.

Mac

The quickest way: open Terminal (⌘Space, type Terminal), paste this and press Return.

curl -fsSL https://raw.githubusercontent.com/sgwork004-max/quire/main/scripts/install.sh | sh

Or download the .dmg and drag Quire to Applications. Quire isn't signed with a paid Apple certificate yet, so the first time:

  1. Right-click Quire in Applications and choose Open, then Open again.
  2. On macOS 15 or later: if it's blocked, go to System Settings › Privacy & Security and click Open Anyway.

Windows

Download the installer and run it.

If Windows SmartScreen says it protected your PC, click More info, then Run anyway. It shows this for new apps without a paid certificate.

All versions are on GitHub Releases.

Questions

Is it really free?

Yes. Quire is open source (AGPL-3.0). Sharing includes 25 MB of cloud space per account, which holds hundreds of typical pages, since only files you share use it.

Do I need an account?

No. Viewing, organising, editing and importing work without one. Sign in with Google only when you want to share a file or comment with others.

Does Quire change my original files?

Files it imports from Downloads or your Desktop are copied into Quire, and the originals are left alone. Folders you add under “On this Mac” stay where they are, and edits you make change those files directly, with every version kept.

Why does my Mac warn me the first time?

Apple shows that for apps not signed with a paid developer certificate. Quire's code is public and every update is signed, so installed copies only accept real updates from this project.

What do the people I share with need?

Quire, and a Google account with the email you invited. The file then appears in their “Shared with me”, and you work on it together live.
